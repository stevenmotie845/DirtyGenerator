# Explicit Adult Content Generator - Seductive Black & Purple Edition

An immersive, beautifully styled web application featuring a luxurious seductive black and purple noir theme.

## Features:
- **Explicit Phrases Engine**: Generates highly explicit phrases with randomized subjects, actions, numbers, and contexts.
- **Character Story Mode**: Generates multi-paragraph explicit stories featuring custom titles, names, and debauched scenarios.
- **Seductive Black & Purple Theme**: Dark obsidian backgrounds (#07030d), rich purple neon glows, custom scrollbars, and sleek glassmorphic UI.
- **Instant Clipboard Copy**: One-click copy with dynamic status feedback.

## Files Included:
- `index.html`: Main user interface.
- `style.css`: Seductive dark/purple styling.
- `script.js`: Generator engine logic and datasets.
- `README.md`: Project documentation.
